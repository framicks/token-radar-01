Token Radar ranks 198 pre-token protocols by implied value: what a token would be worth if the protocol kept its record. The multiple is not a house constant — it is the market's own, the median market-cap-to-TVL ratio each category's live-token protocols trade at, read from the same sealed DefiLlama snapshot. The dashboard is a static page with a sortable, filterable board, a detail view for every protocol with its model breakdown and a seven-step farm plan, a benchmark table, and a sandbox that re-runs the model live.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```
